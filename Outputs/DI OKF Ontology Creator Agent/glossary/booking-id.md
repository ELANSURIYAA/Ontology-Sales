# Booking ID

## Business Definition

Unique identifier for an individual booking transaction.

---

## Technical Mapping

**Source Table**: quotetobooking.fact_bookings  
**Source Column**: booking_id  
**Entity**: Booking Fact  
**Attribute**: Booking ID

---

## Business Meaning

Booking ID is the primary key that uniquely identifies each booking transaction in the fact table. It serves as the unique identifier for tracking and referencing individual booking records.

---

## Synonyms

- Transaction ID
- Booking Number
